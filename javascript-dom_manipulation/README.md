# JavaScript - DOM Manipulation

This project contains JavaScript exercises for DOM manipulation.

## Files

* `0-script.js` - Script that changes header text color to red
* `1-script.js` - Script that changes header color to red on click
* `2-script.js` - Script that adds red class to header on click
* `3-script.js` - Script that toggles header class between red and green
* `4-script.js` - Script that adds list item on click
* `5-script.js` - Script that updates header text on click
* `6-script.js` - Script that fetches and displays Star Wars character name
* `7-script.js` - Script that fetches and lists Star Wars movies
* `8-script.js` - Script that fetches and displays hello translation

## Requirements

* Chrome browser (version 57.0 or later)
* Code is semistandard compliant
* No use of `var`
